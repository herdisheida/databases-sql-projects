# Databases and SQL Projects


A collection of database projects developed in **PostgreSQL** (`psql`) at Reykjavík University (*Gagnasafnsfræði*).
These projects demonstrate end-to-end database engineering: translating ER diagrams and business rules into DDL schemas with trigger-enforced integrity, as well as writing advanced SQL queries.
